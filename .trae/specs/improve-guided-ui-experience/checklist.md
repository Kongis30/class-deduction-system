# Checklist

- [x] 管理员和员工侧边栏第一层只展示 Registration、1-on-1 Lessons、Classrooms、Reports 四个日常入口。

- [x] 管理员低频配置入口仍可访问，但不与四个日常入口混在一起。

- [x] 管理员和员工登录默认进入 Registration，老师和学生默认进入各自受限入口。

- [x] Students 不作为第五个一级入口，学生查找、历史报名表和补记付款可从 Registration 或 Reports 上下文进入。

- [x] 关键页面优先展示表单或表格主体，没有新增复杂卡片、折叠或多层隐藏入口。

- [x] 报名页保持客户熟悉的纸质表单视觉和打印效果。

- [x] 报名页 Save 与 Print 职责继续完全分离。

- [x] 报名页费用区清楚展示 Amount due、Paid、Balance，并显著提示欠费。

- [x] 报名提交成功后提供 Print receipt、View student history、Create another registration 等明确下一步。

- [x] 1-on-1 Lessons 按老师和学生组织消课表，清晰展示 total hours、used/assigned hours、remaining hours。

- [x] 1-on-1 Lessons 清晰区分待老师确认、待管理员确认、已完成、异常或驳回状态。

- [x] 1-on-1 Lessons 保留单个学生消课表打印入口，打印时隐藏导航、按钮和系统 UI。

- [x] Classrooms 明确报名阶段无需教室，教室信息为后续运营补录。

- [x] Reports 保持接近 Excel 的宽表，展示报名、费用、付款、余额、接送和 1 对 1 课时字段。

- [x] Reports 对欠费、报名周期临近到期和 1 对 1 低课时记录提供高亮。

- [x] 新增系统 UI 文案不引入中文，报名纸质表单既有中英双语例外不被破坏。

- [x] 前端类型检查和构建通过。
