# Checklist

- [x] 教师登录后默认进入 My Calendar，且菜单仅显示 My Calendar 和 My Lessons。
- [x] 教师只能查看本人被安排的一对一和班课课次，不能通过请求参数或 URL 查看其他老师的数据。
- [x] 教师 My Lessons 默认显示未来 30 天和待处理课次，并可查看历史课次状态。
- [x] 教师可对本人、处于确认窗口内的一对一课次提交出勤，提交后不立即完成最终消课。
- [x] 教师可对本人、处于确认窗口内的班课课次提交出勤；所有符合资格的班课学生记录进入 Awaiting admin review。
- [x] 管理员审核班课或一对一老师提交的出勤后，系统才完成最终确认及其后续业务影响。
- [x] 管理员驳回后，老师能看到原因并可重新提交对应课次。
- [x] 学生登录后默认进入 My Calendar，菜单中不显示 My Lessons、管理入口或消课操作。
- [x] 学生 My Calendar 默认仅显示未来 30 天，并可切换到历史课次及面向学生的状态。
- [x] 学生端不显示课程余额、内部审核状态、驳回原因、课时台账、老师工资或其他学生资料。
- [x] 老师或学生账号缺少有效档案绑定时，系统不返回业务数据，并显示明确提示。
- [x] 前端类型检查、生产构建和受影响后端测试通过。
