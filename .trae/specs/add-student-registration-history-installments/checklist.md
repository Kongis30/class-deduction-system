# Checklist

- [x] 学生列表展示已报名学生运营字段：最近报名日期、报名次数、应收、已收、余额和付款状态。

- [x] 学生列表支持按姓名、家长电话、校区、付款状态、是否有报名订单和有效状态筛选。

- [x] 未报名学生仍可在学生列表中查看，并明确标记为 `No enrollment`。

- [x] 点击学生可以查看基础资料、报名订单历史、课程摘要、付款进度和操作入口。

- [x] 某个学生的每笔报名订单都可以打开历史报名表回看页面。

- [x] 历史报名表使用与 `/registration` 一致的纸质表单视觉结构。

- [x] 历史报名表数据来自订单快照、订单明细、付款流水和收据快照，不被当前学生资料或课程配置覆盖。

- [x] 历史报名表回看模式隐藏所有编辑按钮，只保留打印和 EIN 显隐能力。

- [x] 历史报名表打印时隐藏导航、侧边栏和所有交互按钮。

- [x] 学生详情或订单详情支持对未结清订单追加付款。

- [x] 追加付款支持多笔记录，每笔可以使用不同支付方式、金额、付款日期、经办人和备注。

- [x] 后端阻止新增付款总额超过订单当前余额，并返回明确错误。

- [x] 追加付款成功后，订单已收、余额、付款状态、学生列表和后台数据整理同步更新。

- [x] 学生详情、订单详情和历史报名表都展示完整付款时间线。

- [x] 新报名保存、报名表打印、历史收据打印、后台数据整理和 1 对 1 消课链路无回归。
