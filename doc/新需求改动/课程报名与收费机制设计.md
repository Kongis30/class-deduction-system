# 课程报名与收费机制设计

> 状态：✅ 核心模型已按兼容方案落地。系统已支持管理员自定义产品、套餐单位/数量/总价、班课全天/半天价格、报名按套餐总价收费。
> 目标：系统不写死任何课程类型，让机构管理员自行创建**任意课程产品**和**任意收费套餐**；收费按套餐总价，倒推的单位费率仅作参考展示。
>
> 本文档为“活文档”，客户补充需求后持续更新。

---

## 1. 设计原则（不可动摇的底线）

1. **不写死课程类型**：课后班、周六班、暑假班、1对1 等都只是客户的例子，不是系统内置类别。系统只提供“课程产品 + 价格套餐”的通用能力。
   - **`courseType` 枚举字段彻底删除**（AFTER_SCHOOL/SATURDAY/SUMMER/SPRINT 等），课程的区分完全由**产品名称**承担。`teachingMode`（ONE_ON_ONE / GROUP）保留，因为它决定报名与消课行为。
2. **套餐独立定价、允许非线性**：同一课程的不同数量套餐各自独立设总价，不能用“单位费率 × 数量”线性计算。例：2 个月 $2000、6 个月可以是 $5400 而不是 $6000。
3. **总价是收费事实来源**：`单位费率 = 套餐总价 ÷ 权益数量` 只是参考、展示、分析数据，不参与实际收费。
4. **报名直接选套餐**：报名时选择已配置好的套餐即可，不再“选套餐后自由填月数再线性算价”。
5. **收费权益 ≠ 实际可用权益**：买了 60 小时套餐、赠 2 小时，收费仍按 60 小时套餐，可用课时是 62 小时。
6. **四层价格分离**：套餐定价 / 活动促销价（走 discount）/ 订单级优惠 / 分期付款（Partial Paid）各自独立、可组合。
7. **全链路可串联**：报名 → 收费 → 有效期 → 排课 → 课次权益 → 消课，必须能完整贯通。
8. **计量单位收敛为 4 种**：MONTH / WEEK / SESSION / HOUR。**不设 FIXED**（客户无纯项目制课程，暑假班 7 周用 WEEK 表达即可）。

## 2. 核心实体层级

```
Course Product（课程产品，管理员自建）
   │  例：G1-5 课后班、SHSAT 周六班、K-5 一对一（区分完全靠产品名称）
   │  属性：名称、教学模式 teachingMode(ONE_ON_ONE/GROUP)、科目/年级标签、校区适用范围、启用状态
   │  （删除 courseType 枚举字段）
   │
   ├── Class Schedule（班课排课，仅 GROUP 需要）
   │      - 设置一套完整排课，如：周六 9:00-16:00
   │      - 可设置可报名时段 attendanceOption：全天 / 上午 / 下午
   │      - 上午/下午从完整排课中拆分出来，用于报名后生成该学生的上课时段
   │
   └── Price Package（价格套餐，独立可售 SKU，一个产品可挂多个）
          属性：
            - 计量单位 unit：MONTH / WEEK / SESSION / HOUR（无 FIXED）
            - 权益数量 quantity：如 2（月）、13（周）、40（小时）
            - 套餐总价 totalPrice：实际收费依据（=宣传单原价）
            - 倒推单位费率 derivedUnitRate = totalPrice / quantity（仅展示）
            - 套餐名称 packageName：如“秋季 13 周”“春季 20 周”“全年 33 周”“40 小时”
            - 有效期：从报名 start day 起按 unit 推算的非滚动周期
            - 适用范围：校区、年级、科目
            - 启用状态
          （不再需要 Promotion 促销实体；早鸟/连报价一律走订单 discount）

Enrollment Order（报名订单）
   │  选定一个套餐 → 生成收费 + 生成课时/有效期权益
   ├── attendance option：班课报名时选择全天 / 上午 / 下午（如适用）
   ├── start day：可手动设为过去日期（中途插班）
   ├── 附加费 surcharge：报名时自由填写（金额 + 说明），如暑假托管 $100
   ├── 订单级优惠 Discount：沿用现有功能（早鸟/连报/手牵手/老带新/好评均走此处）
   ├── 应收 = 套餐总价 − discount + 附加费
   ├── 已付 / 未付（Partial Paid）
   └── Course Package（学生课包，承载实际可用权益）
          - 购买权益 purchasedUnits（对应套餐数量，收费口径）
          - 可用权益 availableUnits（含赠课，消课口径）
          - 有效期 startDate（= start day） / endDate（按 unit 非滚动推算）
          - 多老师额度分配（手动，非平均）
```

## 3. 客户真实课程产品类型分析（4 张宣传单）

用来验证“通用模型能否表达客户的所有课程”。结论：**4 类课程全部能用 产品 + 套餐(unit/quantity/totalPrice) + 报名时段(attendance option) 表达**，§4 的扩展点已全部确认。

### 3.1 课后班（图 1）—— 计量单位 MONTH，非线性
- 上课周期：9/10/26–6/28/27，周一至周五 3:00–6:00 PM。
- 套餐数量：双月(2 月) / 半年(6 月) / 全年(≈10 月)。
- 产品 × 套餐价：

| 产品（年级/科目） | 双月价 | 半年价 | 全年价 |
|---|---|---|---|
| 小学部 G1-5 | $800 | $2,199 | $3,499 |
| 初中部 SHSAT | $880 | $2,399 | $3,899 |
| ESL 新移民英文 | $880 | $2,399 | $3,899 |

- **非线性验证**：G1-5 双月 $800 = $400/月，半年 $2199 ≈ $366/月，全年 $3499 = $350/月 —— 数量越多单价越低，**必须套餐各自定价**。✅

### 3.2 周六班（图 2）—— 计量单位 WEEK + “全天/半天”维度 + 早鸟价
- 上课周期：9/12/26–6/12/27。秋季 13 周 / 春季 20 周 / 全年 33 周。
- **多出一个维度：全天(9am–4pm) vs 半天(9–12 / 1–4)**。
- 每格都有“原价 / 八月早鸟价”两个价（促销价分离）。

全天：

| 产品 | 秋季13周(原/早鸟) | 春季20周 | 全年33周 |
|---|---|---|---|
| G1-2基础/G3-6州考/ESL | $1,399 / $1,349 | $2,099 / $1,799 | $3,498 / $2,998 |
| SHSAT/PSAT/SAT | $1,599 / $1,549 | $2,399 / $2,099 | $3,998 / $3,498 |

半天：

| 产品 | 秋季13周 | 春季20周 | 全年33周 |
|---|---|---|---|
| G1-2基础/G3-6州考/ESL | $1,199 / $1,169 | $1,799 / $1,649 | $2,998 / $2,698 |
| SHSAT/PSAT/SAT | $1,299 / $1,269 | $1,899 / $1,749 | $3,198 / $2,898 |

- **验证**：秋/春/全年是不同数量的独立套餐（quantity=13/20/33）；全天/半天是报名时选择的上课时段和价格分支；早鸟价走订单 discount。✅

### 3.3 一对一（图 3）—— 计量单位 HOUR，非线性 + 费率区间
- 套餐数量：40 小时 / 60 小时 / 120 小时。
- 产品 × 套餐价：

| 产品（年级段） | 参考小时费 | 40h | 60h | 120h |
|---|---|---|---|---|
| K-5 | $50–60/h | $2,399 | $3,299 | $5,999 |
| 6-8 | $60–70/h | $2,799 | $3,899 | $7,299 |
| 9-12 | $70–80/h | $3,199 | $4,499 | $8,399 |
| AP/AMC10/AMC12 | $80–90/h | $3,599 | $5,099 | $9,599 |

- **非线性验证**：K-5 40h=$60/h，60h≈$55/h，120h=$50/h。✅
- **“Starting from $50/h (up to $60/h)”**：宣传单上的费率区间只是参考展示，真实收费仍看套餐总价。倒推费率正好落在区间内 → 用 `derivedUnitRate` 展示即可。✅

### 3.4 暑假班（图 4）—— 计量单位 WEEK(固定 7 周) + 半天/全天 + 早鸟价
- 上课周期：7/6–8/21，共 7 周 35 天。半天 9–12 / 全天含下午。
- 每格“早鸟价 / 原价”。

| 产品 | 半天(早鸟/原价) | 全天(早鸟/原价) |
|---|---|---|
| 小学部 G1-5 | $1,549 / $1,599 | $1,849 / $1,899 |
| SHSAT 预备班(6升7) | $1,649 / $1,699 | $1,949 / $1,999 |
| SHSAT 加强班(7升8) | $1,849 / $1,899 | $2,349 / $2,399 |
| PSAT(9-10) | $1,849 / $1,899 | $2,349 / $2,399 |
| SAT(10-12) | $1,849 / $1,899 | $2,349 / $2,399 |
| ESL | $1,649 / $1,699 | $1,949 / $1,999 |

- **验证**：固定 7 周是一个 WEEK(quantity=7) 套餐；早鸟价走订单 discount；全天/半天是报名时选择的上课时段和价格分支。✅
- **托管附加费**：暑假班“最晚托管到 6 点需额外 $100” → 报名时用自由填写的附加费字段表达。见 §4.3。

### 3.5 报名实例演算（客户举例，固化理解，防止偏差）

**例 1：3 年级报周六班秋季半天**
- 家长直接看宣传单表格找到对应格子：`3 年级 → 周六班 → 秋季 → 半天 = $1,199`（原价）。
- 系统里：选产品「周六班 G1-2基础/G3-6州考/ESL」→ 选套餐「秋季 13 周」→ 选上课时段「半天-上午」或「半天-下午」。
- 半天价格分支为 $1,199；全天价格分支为 $1,399。系统按管理员选择的上课时段带出对应价格。
- **直接按这个套餐格子的总价 $1,199 收费**，不做任何按周线性计算。
- 秋季 = 13 次课（13 周），报名后按该学生选择的上课时段走排课日历消课。
- 若在 8/31 前报名享早鸟 → 管理员用 discount 手动减 $30，应收 = $1,199 − $30 = $1,169（与宣传单早鸟价一致）。

**例 2：课后班按月，月费率随套餐不同**
- 报 2 月、6 月、10 月是**三个独立套餐**，每个套餐的“每月费率”都不同（非线性）。
  - G1-5：2 月 $800（$400/月）、半年 $2,199（≈$366/月）、全年 $3,499（$350/月）。
- 报名时**只选套餐、付套餐总价**，系统不会拿某个“月费”去乘月数。
- `derivedUnitRate = totalPrice / quantity` 仅用于展示“折合每月多少钱”，不参与收费。

> 核心结论：**报名 = 选产品 + 选套餐 + 选上课时段（如适用）+ 按对应总价收费**。费率是配置套餐时倒推出来给人看的，不是收费依据。

## 4. 关键扩展点（客户已确认）

### 4.1 「全天/半天/上午/下午」—— ✅ 报名时选择上课时段
- **决定**：先按一个班课设置完整排课，例如周六 9:00-16:00；报名时让管理员选择该学生报“全天”还是“半天”。
- 如果选择“半天”，再选择“上午”或“下午”。系统根据选择使用对应上课时段：
  - 全天：9:00-16:00
  - 上午：9:00-12:00
  - 下午：13:00-16:00
- 产品和套餐仍然只负责“报什么课、报多久、多少钱”。上课时段是报名订单上的选择，不让管理员理解 `variant/spec` 这类内部字段。
- 价格上：同一个套餐可以按上课时段配置不同总价，如“秋季 13 周：全天 $1399，半天 $1199”。

### 4.2 早鸟价 / 促销价 —— ✅ 用现有 discount 管理，不额外改动
- **决定**：早鸟价、连报价等一律由管理员在报名时通过**现有订单级 discount 功能**手动设置。
- 系统**不需要**新增 Promotion 促销实体、不需要按日期自动触发。套餐只维护原价（总价）。

### 4.3 附加费（暑假班托管 $100 等）—— ✅ 报名时自由填写的附加费字段
- **决定**：报名时提供一个**自由填写的附加费字段**（金额 + 可选说明），计入应收。
- 不需要“可配置加购项清单”。

### 4.4 订单级优惠 —— ✅ 现有 discount 功能够用，不需管理其它优惠
- **决定**：手牵手、老带新、好评、介绍费等一律用现有 discount 功能处理或线下处理，系统**不需要**为这些优惠类型做任何改动。

### 4.5 有效期规则 —— ✅ 从报名日开始的非滚动周期
- **决定**：所有套餐有效期统一为**从报名日（start day）开始按单位推算的非滚动周期**。
  - 例：5/15 报 2 个月 → 有效期到 6/30（非滚动月）。
  - WEEK/HOUR/SESSION 型按各自单位从 start day 推算终止日或用完为止。
- 不使用“套餐固定学期起止日期”。

### 4.6 假期校历 —— ✅ 暂时不需要
- **决定**：系统暂不维护校历/假期，不做自动排课跳过。假期只在人工排课时由管理员把控。

### 4.7 中途插班（学期已开始才报名）—— ✅ 手动设置 start day + 手动折扣
- **决定**：中途插班时，管理员把报名的 **start day 设置成之前的日期**（有效期据此推算），价格由管理员**咨询后手动用 discount 折扣**。
- 不做“按剩余单位自动折算”，避免破坏非线性定价原则。

## 5. 用户操作流程设计（降低学习成本）

### 5.1 创建班课产品

页面上只让管理员看到业务字段：

1. 填课程名称：如 `周六班 G1-2基础/G3-6州考/ESL`。
2. 选择教学模式：`班课`。
3. 填科目/年级/校区等标签。
4. 设置完整排课：可以是一周一次，也可以一周多次。
   - 周六班：`每周六 9:00 AM - 4:00 PM`
   - 暑假班：`周一至周五 9:00 AM - 4:00 PM`
   - 课后班：`周一至周五 3:00 PM - 6:00 PM`
5. 对每个上课日勾选可报名时段：
   - `全天`
   - `上午半天`
   - `下午半天`

页面文案建议：

```
Class schedule
Saturday 9:00 AM - 4:00 PM
Available attendance options: Full day / Morning half day / Afternoon half day

For a multi-day class, add each class day:
Mon 9:00 AM - 4:00 PM
Tue 9:00 AM - 4:00 PM
Wed 9:00 AM - 4:00 PM
```

管理员不需要理解 `unit`、`variant`、`class group` 等系统字段。

### 5.2 设置套餐价格

管理员在产品下添加套餐，例如：

| 套餐名称 | 单位 | 数量 | 全天价格 | 半天价格 |
|---|---|---:|---:|---:|
| 秋季 | Week | 13 | $1,399 | $1,199 |
| 春季 | Week | 20 | $2,099 | $1,799 |
| 全年 | Week | 33 | $3,498 | $2,998 |

页面文案建议：

```
Add package
Package name: Fall
Length: 13 weeks
Full day price: 1399
Half day price: 1199
```

如果某个产品没有半天/全天差异（如课后班、1对1），价格表就只显示一个 `Package price`，不要展示无关字段。

### 5.3 学生报名

管理员报名时的选择顺序：

1. 选择学生。
2. 选择课程产品：如 `周六班 G1-2基础/G3-6州考/ESL`。
3. 选择套餐：如 `秋季 13 周`。
4. 选择上课时段：
   - `全天 9:00 AM - 4:00 PM`
   - `上午半天 9:00 AM - 12:00 PM`
   - `下午半天 1:00 PM - 4:00 PM`
5. 如果这个班一周有多次课，半天报名要按每个上课日选择上午或下午。例：暑假班周一至周五，学生可以选择“每天上午”，也可以逐日选择“周一上午、周二下午、周三上午...”。
6. 系统自动带出套餐价格。
7. 管理员填写 start day、discount、附加费、付款金额。

报名页必须直接展示人能理解的结果，例如：

```
Course: 周六班 G1-2基础/G3-6州考/ESL
Package: Fall - 13 weeks
Attendance: Morning half day, Saturday 9:00 AM - 12:00 PM
Price: $1,199
```

### 5.4 排课和消课

- 班课只需要设置完整排课一次，如周六 9:00-16:00。
- 学生报名后，系统根据他选择的上课时段生成该学生的实际上课窗口。
- 如果一周有多次课，学生的报名时段是“每个上课日一条规则”，例如周一上午、周二上午、周三下午。
- 点名和消课时，系统只显示该学生应该出现的时段。
- MONTH/WEEK 型班课仍按排课日历消课。

## 6. 计量单位行为矩阵（草案）

| 单位 | 数量含义 | 有效期（统一：从 start day 非滚动推算） | 排课/消课口径 | 典型产品 |
|---|---|---|---|---|
| MONTH | 月数 | start day 起非滚动月（5/15 报 2 月 → 6/30） | ✅ 按排课日历消课 | 课后班 |
| WEEK | 周数 | start day 起 N 周 | ✅ 按排课日历消课 | 周六班、暑假班（7 周） |
| SESSION | 课次数 | 用完为止（可加到期日） | 每次课扣 1 次 | 按次收费的班课 |
| HOUR | 小时数 | 用完为止（可加到期日） | 每次课按时长扣（内部 0.5h/单位） | 一对一 |

> 有效期已统一为“从报名 start day 起按 unit 非滚动推算”（§4.5）。
> 消课口径已确认：MONTH/WEEK 型班课**按排课日历消课**；一对一按小时扣、SESSION 按次扣。
> FIXED 单位已删除；暑假班 7 周用 WEEK(quantity=7) 表达。需求全部锁定。
