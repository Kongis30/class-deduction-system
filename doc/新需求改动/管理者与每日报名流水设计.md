# 管理者账号与每日报名流水

## 已确认业务规则

- 每日报名流水位于左侧主菜单末尾，按报名记录实际保存时间 `created_at` 归日，并可按日期追溯。
- 一次订单包含多名学生或多门课程时，流水按学生与课程拆分展示；同时统计报名条目数和去重学生数。
- 流水展示报名金额、实收金额、欠款金额和经手人；经手人身份由后端从登录会话取值，不能信任客户端传入的姓名或用户 ID。
- 系统管理员可以创建、停用管理者账号。管理者可使用后台业务功能、创建报名和录入正向收款。
- 管理者不能执行退款、调整学生 Credit 余额、修改已保存收据或执行其他资金流出操作。
- 管理者可以访问 Data Summary 的非金额业务信息，但 API、页面、汇总卡片、筛选和 Excel 导出均不暴露金额数值字段。
- 系统管理员可在每日报名流水中按管理者查看报名条目数及去重学生数。

## 当前代码复用

- 报名创建沿用 `RegistrationIntakeService`，该流程已支持一个订单包含多个学生和课程。
- 每日报名流水复用 `DataSummaryService` 生成的课程/学生级数据行及现有金额分摊结果；新增基于订单 `created_at` 的日期过滤和保存经手人快照，不复制支付/优惠计算。
- `sys_user`、`sys_role`、`sys_user_role` 继续承载后台账号及角色；新增 `MANAGER` 角色和仅管理员可调用的管理者账号接口。
- `enrollment_order` 增加不可由客户端填写的报名操作人 ID 与姓名快照，用于审计和历史统计；保留 `cashier_user_id` 原有收银员语义。

| 操作 | ADMIN | STAFF | MANAGER |
| --- | --- | --- | --- |
| 创建报名、生成报名收据 | 允许 | 允许 | 允许 |
| 录入正向付款 | 允许 | 允许 | 允许 |
| 浏览每日报名流水与金额 | 允许 | 允许 | 允许 |
| 按操作人查看报名统计 | 允许 | 允许 | 允许 |

| 管理管理者账号 | 允许 | 禁止 | 禁止 |

## 实现及验证范围

1. 添加可重复执行的数据库迁移，为订单写入报名操作人快照，并引入 `MANAGER` 角色。
2. 新增系统管理员专用的管理者账号创建、列表、编辑/停用接口和配置页。
3. 在现有角色授权基础上开放一般后台业务权限，并对退款、收据更正、Credit 调账等资金流出或已保存财务数据修改接口做后端专门限制。
4. 新增按保存时间范围查询的每日报名流水接口，返回学生/课程行、应收/实收/欠款、经手人及按经手人汇总。
5. 对 Data Summary 的管理者响应剔除所有金额数值字段，并同步隐藏页面金额列、金额统计、金额筛选和 Excel 导出列。
6. 验证多学生/多课程拆行、保存时间跨日边界、历史经手人、管理员统计、收款成功、退款/调账拒绝、Data Summary 响应脱敏及导出权限。

## 实施默认值

- 日期边界采用系统用户时区 `America/New_York`，日期结束按次日零点排除。
- 历史订单没有新经手人快照时，流水显示既有 `handled_by_name`，操作人 ID 尽力使用 `cashier_user_id` / `created_by` 回填，无法识别的记录显示为未记录。
- 管理者的 “MANAGER” 身份以角色码区分，`user_type` 仍为 `STAFF`，以保留当前后台工作区和既有登录流程。
