# 课程级班课放假

## 业务范围

- 每个班课 Course 单独维护多段放假日期；该 Course 下所有校区和实际班级共用这些日期，其他 Course 不受影响，一对一课程不受影响。
- 日期区间首尾均包含。同一 Course 的多个放假区间不能重叠，不同 Course 的日期区间可以重叠。
- 放假期间不生成该 Course 的班课课次，也不能把该 Course 的班课手动调入放假日期。
- 已开始或已有消课记录的课次不可被放假设置取消；操作必须整体失败并提示管理员先处理这些课次。
- 放假只影响课程安排，不改收据金额。SESSION 课包按实际上课日计算，到期日随该 Course 的放假顺延；若顺延超出实际班级结束日，则拒绝保存并提示调整班级周期。MONTH/WEEK 仍遵循报名时的固定日历周期。

## 数据与状态

- `course_holiday` 以 `course_product_id` 关联一个班课 Course，保存假期名称、开始日、结束日和审计字段。
- `lesson_occurrence` 保留被放假影响的班课课次，标记对应的 Course 假期以及取消前的排课状态。撤销/缩短假期时，可恢复原课次状态；人工取消的课次不会被恢复。
- 放假创建、修改、删除、该 Course 的课次状态同步和 SESSION 报名到期日重算在同一事务中完成。

## 上下游约束

- 所有班课课次生成入口和每日续排任务都按班课所属 Course 查询假期；不能只在 Schedule 页面隐藏记录。
- Prices 页实际班级排课的修改、Schedule 单次改课和周调课均拒绝该 Course 的放假日期。
- SESSION 报名计算到期日时跳过所属 Course 的假期。既有在册报名在该 Course 假期变化时同步重算。
- Schedule、班课消课和学生日历继续消费 `lesson_occurrence`；假期取消的课次不作为可排/可消课次返回。
- 不改 1on1 occurrence、已确认消课历史、付款、折扣及收据金额。

## 管理入口

Prices 页面选择一个 Group Class Course 后，顶部提供该 Course 的假期管理入口。管理员可增改删多个区间；保存前展示该 Course 受影响的课次数、SESSION 报名数和阻止保存的冲突。
