# 全局班课放假

## 业务范围

- 放假区间属于系统级班课日历，对所有校区、课程和实际班级生效；一对一课程不受影响。
- 日期区间首尾均包含。多个区间不能重叠。
- 放假期间不生成班课课次，也不能把班课手动调入放假日期。
- 已开始或已有消课记录的课次不可被放假设置取消；操作必须整体失败并提示管理员先处理这些课次。
- 放假只影响课程安排，不改收据金额。SESSION 课包按实际上课日计算，到期日随放假顺延；若顺延超出实际班级结束日，则拒绝保存并提示调整班级周期。MONTH/WEEK 仍遵循报名时的固定日历周期。

## 数据与状态

- `class_holiday` 存放全局放假名称、开始日、结束日和软删除审计字段。
- `lesson_occurrence` 保留被放假影响的班课课次，标记其对应假期以及取消前的排课状态。撤销/缩短假期时，可恢复原课次状态；人工取消的课次不会被恢复。
- 放假创建、修改、删除、课次状态同步和 SESSION 报名到期日重算在同一事务中完成。

## 上下游约束

- 所有班课课次生成入口和每日续排任务共用放假日历；不能只在 Schedule 页面隐藏记录。
- Prices 页实际班级排课的修改、Schedule 单次改课和周调课均拒绝放假日期。
- SESSION 报名计算到期日时跳过所有全局假期。既有在册报名在假期变化时同步重算。
- Schedule、班课消课和学生日历继续消费 `lesson_occurrence`；假期取消的课次不作为可排/可消课次返回。
- 不改 1on1 occurrence、已确认消课历史、付款、折扣及收据金额。

## 管理入口

Prices 页面 Group Class 模式顶部提供全局假期管理入口，与当前课程选择无关。管理员可增改删多个区间；保存前展示影响的课次数、受影响 SESSION 报名数和阻止保存的冲突。
