# 部分退款业务规则

## 1. 适用范围

部分退款按报名订单的课程明细发起，不按整单任意金额发起。

- 一笔退款必须选择一个或多个课程明细。
- 被退款课程的未来服务资格必须同步关闭：
  - 1-on-1：取消未来未确认课次并关闭对应课包。
  - 班课：撤销对应班课资格，未来课次不再计入该学生。
- 同一课程明细可以多次退款，但累计退款不得超过该明细的可退金额。

整单全额退款继续沿用现有流程，不使用本规则。

## 2. 金额定义

对每个课程明细计算以下金额：

- `课程净价`：课程标价减去按课程标价占比摊销的订单折扣。
- `课程实收分摊`：订单净实收按未退款课程明细的课程净价比例分摊；累计不得超过课程净价。
- `已使用金额`：课程净价乘以已使用比例。
- `可退上限`：课程实收分摊减去已使用金额，最小为零。

退款金额必须满足：

```text
0 < 本次退款金额 <= 可退上限
```

系统默认生成等于 `可退上限` 的建议金额；员工可以在该上限内下调金额并填写原因。

## 3. 已使用比例

仅最终确认且实际扣课或占课的记录视为已使用：

- 1-on-1：`已使用比例 = 已扣课单位 / 总购买课时单位`。
- 按课次班课：`已使用比例 = 最终占课次数 / 已购买课次数`。
- 月费班课：`已使用比例 = 最终占课次数 / 已购月份内计划课次数`。

Formal Leave、未最终确认记录、被驳回记录不计入已使用比例。

比例和金额计算保持高精度，最终退款金额按货币两位小数四舍五入。

## 4. 分期付款与欠费

退款采用“实收分摊封顶”规则，不新增欠费。

示例：

```text
课程净价：$600
该课程已分摊实收：$500
已使用比例：50%
已使用金额：$300
可退上限：$500 - $300 = $200
```

退款 $200 后，该课程保留已使用服务对应的 $300 实收，不形成新的待收余额。

订单级数据同步更新：

```text
订单实收 = 退款前实收 - 本次退款
订单余额 = 应收 - 订单实收
付款状态按更新后的订单实收和余额重新计算
```

课程已关闭后，不允许继续补款；订单中其他未退款课程仍可按原流程补款。

## 5. 费用与折扣

- 订单折扣按各课程标价占比摊销到课程净价。
- 接送费和额外费用默认不退。
- 员工可显式选择退还某项接送费或额外费用；所选费用单列退款，不参与课程折扣比例计算。
- 费用项累计退款不得超过该费用项已分摊实收。

## 6. 工资与历史凭证

- 已最终确认的课次不回滚，已生成或已支付的老师工资不自动冲销。
- 未来未确认课次被取消后，不进入老师待支付。
- 原始收据永久保留；每次部分退款生成独立负向付款流水和退款凭证，并关联原订单、课程明细及费用项。
- 数据汇总同时展示课程原价、折扣、实收、退款、净实收和已使用金额；不可将部分退款订单整体排除。

## 7. 实现前置条件

实现需要新增或扩展：

- 付款流水与课程明细/费用项的分摊记录。
- 课程明细、课包、班课资格的退款累计金额与状态。
- 退款凭证和原收据关联。
- 部分退款后的订单、学生历史、Data Summary 和老师工资审计用例。
