5. 构造一节进行中课程：详情标记 In progress，重排返回 `LESSON_IN_PROGRESS`，不回收该课。
6. 两个数据库事务并发：先读取待回收清单，另一事务锁住旧课次并变更版本；重排等待锁约 3 秒后返回 `PENDING_LESSONS_CHANGED`，旧课次未删除，原活动规则仍只有一条。另在保存前串行改变课次版本也得到同样拒绝。
