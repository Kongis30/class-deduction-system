## 修复内容
订单行软删后收据快照仍保留旧行时，`findOrderItemFallback` 索引兜底会借用未删行的 orderItemId，
导致快照多行共用同一 ID，Edit Receipt 换课保存时误报
"Original course rows cannot be removed or replaced"。修复：
- orderItemId 解析链补上 `enrollmentOrderItemId`（老快照格式）
- 支持按 `enrollmentOrderItemId` 精确匹配
- 有身份线索但匹配不到（订单行已删）时返回 null，不走索引兜底

触发场景（生产数据）：Ze Mu Ma 订单 EO202609130008 两行州考冲刺班，line_no=1 已软删，
Edit Receipt 换第一行课程后保存失败。
