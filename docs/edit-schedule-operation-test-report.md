## 口径与测试基准

课包 Total、Starting、Remaining 在只改排课时保持不变。老师的 Allocated、Deducted、Remaining 分别为当前周期分配、当前周期已最终扣除、两者之差。历史时间线按管理员选定的旧 slot → 新 slot 显示；历史实际老师、课次和扣课流水不应变化。

## 当前结论

此前曾依据旧假设将起始日前普通旧课被替换判为失败；用户已明确保存重排立即结束旧规则，临时拦截已移除。隔离库以 Bowen 快照实测：选 11/28 起始，10/31 未开始普通课被替换，新课 11/28 及 12/02 共 2.5h；课包、11 条确认历史及流水不变，1-on-1 老师为 2.5 / 0 / 2.5h。再次制造老师冲突时，七张业务表校验值前后一致。浏览器模拟接口测试覆盖未来日期及即时终止提示；自动化服务测试覆盖历史保留及起始日。已开始待处理课、人工调整、补课等例外按既定规则处理，未来日期与这些例外的组合仍需完整验证。

Bowen 的旧本地备份缺少周期边界，造成 14h 误计；线上快照对应边界已存在，不能将单条数据结论推广到其他规则。共享课包、消课并发及其他异常组合仍待验证。
