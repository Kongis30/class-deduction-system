# 页面加载优化记录

本记录保留每次优化的范围、环境、测量方法和结果。接口耗时是客户端从发送请求到读取完整响应的时间，不包括浏览器渲染；本地结果不代表线上速度。

## 2026-10-31：启用响应压缩

- 环境：本机 Java 服务及 MySQL 中的线上数据副本，认证为管理员；关闭测试服务的定时任务。请求通过本机回环地址，数据库和服务均已预热。
- 方法：同一服务分别请求 `Accept-Encoding: identity` 与 `gzip`，先预热一次，之后各测 5 次，记录中位数。响应内容对比 `data` 字段；响应时间戳每次不同。

| 接口 | 原始字节 | gzip 字节 | 原始中位耗时 | gzip 中位耗时 | 业务数据 |
| --- | ---: | ---: | ---: | ---: | --- |
| Data Summary | 464,990 | 约 41,300 | 88.6 ms | 85.9 ms | 一致 |
| Schedule 学生列表 | 21,541 | 2,683 | 7.1 ms | 7.0 ms | 一致 |
| 1-on-1 消课列表 | 1,490,699 | 71,541 | 155.5 ms | 156.1 ms | 一致 |

本机回环测试没有模拟公网带宽或高延迟，不能据此估算线上提速。未协商 gzip 时保留原始响应；小于 2 KB 的响应不压缩。

## 2026-10-31：1-on-1 批量读取课位

- 原因：接口逐个老师、课包组装时间线时重复读取课位；改为在一次请求内按最多 500 个 ID 一批读取，并在老师分组和课次展示中复用。含已删除历史课位，未缓存跨请求数据。
- 方法：相同 Git HEAD 的独立构建，共用同一数据库副本及 gzip 配置；基线与优化服务交替请求，预热后各 8 次，以中位数比较。管理员账号，不包括浏览器渲染。

| 接口 | 优化前中位耗时 | 优化后中位耗时 | 业务数据 |
| --- | ---: | ---: | --- |
| 1-on-1 消课列表 | 161.6 ms | 124.8 ms | 一致 |
| Data Summary（对照） | 89.6 ms | 86.0 ms | 一致 |
| Schedule 学生列表（对照） | 7.8 ms | 6.7 ms | 一致 |

单次本地小样本存在抖动；对照接口未修改，耗时差异不能归因于这项改动。老师、学生、课包、日期窗口筛选结果也与基线一致；`LessonOccurrenceServiceImplTest` 48 项通过。尚需用生产规模数据和真实浏览器验证，并继续处理按课包、按 product 加载等后续工作。

- 使用本地数据库副本及独立构建，Data Summary、Schedule 学生列表和 1-on-1 列表返回的 `data` 与同一 HEAD 基线一致；老师、学生、课包、日期窗口筛选结果也一致。无登录凭据访问 Data Summary 返回 401。

- 该回归不等于全部权限角色、移动端、生产数据规模或写入后刷新均已覆盖；按 product 和按课包分批加载尚未实施。
